📡 PCAP Ingestion

Test Case Generation & Scenario Management

What it does: Parses a PCAP file, extracts TLS handshake parameters, and generates a test scenario that replays the exact same client/server behavior — including handling PFS ciphers by performing live key exchange at runtime.

✅ No external services or AI required — runs entirely locally

📋 Processing Pipeline Detail

1

PCAP Parsing

FunctionModuleWhat it does
readPcap()pcap-parser.jsReads binary pcap file, extracts packets with IP/port/payload + TCP flags (FIN/RST/SYN)
groupStreams()pcap-parser.jsGroups packets into bidirectional streams by 5-tuple, propagates TCP flags
mergeNATStreams()pcap-parser.jsDetects and merges streams split by NAT (IP and/or port rewrite)
⬇
2

TLS Handshake Analysis

FunctionModuleWhat it does
analyzeFullHandshake()pcap-parser.jsReassembles c2s/s2c data, parses TLS records and handshake messages
parseClientHello()tls-validate.jsExtracts version, random, cipher suites, SNI, ALPN, extensions
parseServerHello()tls-validate.jsExtracts selected cipher, version, extensions
parseServerKeyExchange()tls12-crypto.jsExtracts ECDHE curve and public key
extractPublicKeyInfo()pcap-parser.jsExtracts certificate key type (RSA/EC/Ed25519) and size
⬇
3

Scenario Generation

FunctionModuleWhat it does
parsePcapToScenario()pcap-parser.jsDecision tree: abort/TLS1.3/ECDHE/verbatim → scenario object + TCP control actions
extractPostHandshakeActions()pcap-parser.jsExtracts alerts, app data sent after handshake
extractTcpControlActions()pcap-parser.jsExtracts TCP FIN/RST from stream for client and server action lists
buildHandshakeAnalysis()pcap-parser.jsStructured analysis for GUI display
⬇
4

Storage & Lifecycle

💻 CLI Reference

Ingest & Run

# List streams
node cli.js client host 443 \
  --ingest-pcap capture.pcap --list-streams

# Ingest and run (auto-saves)
node cli.js client host 443 \
  --ingest-pcap capture.pcap

# Custom name
node cli.js client host 443 \
  --ingest-pcap capture.pcap \
  --pcap-name my-test

# Run without saving
node cli.js client host 443 \
  --ingest-pcap capture.pcap --no-save

# Distributed mode
node cli.js client host 443 \
  --ingest-pcap capture.pcap --distributed

Manage Tests

# List saved tests
node cli.js pcap-tests

# Run a saved test
node cli.js client host 443 \
  --scenario pcap-tls-session-0

# Run all PCAP tests
node cli.js client host 443 \
  --category PCAP

# Verify (promote to suite)
node cli.js verify-pcap-test \
  pcap-tls-session-0

# Delete
node cli.js delete-pcap-test \
  pcap-tls-session-0
